# 20250927stampdiary

## Stamp Diary

「スタンプ」で気軽に毎日を記録できるカレンダーアプリ。<br>
感情・学習・生活・食事など、カテゴリ別の絵文字をクリックで登録し、自分だけの“スタンプ日記”をつけられます。

## 主な機能

### カレンダー表示
月ごとのカレンダーを自動生成
前月 / 翌月 / 今月に戻るボタンで移動可能
### スタンプ登録
各日付に「右上・左下・右下」の3スロット
絵文字パレットからスタンプを選んで保存
選んだスタンプは Firebase Firestore に保存され、再読み込み後も反映
### カテゴリ別絵文字
感情 😅 / 学習・仕事 💻 / ヘルスケア 💊 / 生活 🧺 / 余暇 🎮 / 食事 🍣 など
スタンプ削除機能
スタンプパレットの「× スタンプ削除/閉じる」ボタンで削除可能
### ユーザー認証
Firebase Authentication の匿名認証を利用
10分間操作がない場合は自動ログアウト

## 技術スタック

### フロントエンド
HTML / CSS (レスポンシブ対応)
JavaScript (ES Module)
## バックエンド / BaaS
Firebase Authentication（匿名認証）
Firebase Firestore（スタンプ保存・取得）
